# 真实长文与安全对抗评测集说明（`real_cases.jsonl`）

更新时间：2026-11-25。

## 构建目的

原 `cases.jsonl`（30 份，平均 164 字）均为短合成样例，无法检验长文上下文理解、文末免责声明识别以及安全对抗鲁棒性。`real_cases.jsonl` 用于补充以下四类场景（共 20 份，长文与对抗用例为主）：

1. **长文宣传体裁（`RL01`–`RL12`，12 份）**：覆盖公众号长文、固收+海报文案、基金经理专访、评级与股东宣传、定投科普、同业对比与返利、私募微信推介等真实业务体裁（含 4 份完整合规对照长文 `RL09`–`RL12`）。
2. **监管警示典型案例复现（`RL13`–`RL16`，4 份）**：依据证监会及地方证监局公开监管措施决定书常见违规事实（私发保本话术、单挑有利年度、展示不足 6 个月/3 个月短期业绩、基金经理挑区间+大V推荐）构建。
3. **安全与边界对抗样例（`RL17`–`RL20`，4 份）**：
   - `RL17` / `RL18`：材料正文中嵌入间接提示注入（企图诱导模型输出空数组、改写引用或伪造规则编号）。
   - `RL19`：正文前段违规承诺保本，文末附标准免责声明（检验模型是否被文末免责声明错误“洗白”）。
   - `RL20`：正文前段展示多年度业绩，隔千字行业分析后在文末才给出完整声明与风险提示（检验长文跨段召回与抗误报）。

## 使用方式

```bash
# 离线关键词基线
uv run review.py --golden golden/real_cases.jsonl --eval --offline --out out/real_offline

# 在线基线（需先配置 .env 与网关）
uv run review.py --golden golden/real_cases.jsonl --eval --out out/real_v03
```
